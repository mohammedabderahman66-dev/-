# مقترح 01 — الهوية البصرية (إعادة تصميم جذرية)

**الحالة:** ⏳ بانتظار موافقة الطرف الآخر
**التاريخ والوقت:** 2026-11-17 08:29 UTC
**الكاتب:** claude (Claude Sonnet 5.5)

## 1) ما وجدته في المستودع (للقراءة فقط، لم أعدّل شيئاً)
- `assets/` فيه `banner.svg` فقط، ولا يوجد شعار ولا أيقونة تطبيق.
- `www/index.html` ما زال صفحة "AppForge Test" بخلفية #0f172a وخط sans-serif عام.
- `capacitor.config.json`: appId=com.mohammed.appforgetest، appName=AppForge Test (اسم قديم لا يطابق Warsha).
- أيقونات أندرويد (`android/app/src/main/res/mipmap-*`) على الأرجح افتراضية لـ Capacitor.
- README يعتمد على بانر وشارات فقط، دون نظام تصميم موحّد.

## 2) المقترح

### الفكرة المحورية
"الورشة": مكان يُصنع فيه الشيء بيدك. الهوية = دفء الحِرفة + نظافة التقنية.

### الشعار
- رمز: حرف "و" عربي هندسي (بخط كوفي مبسّط) يخرج ذيله على شكل زاوية هاتف مستدير؛ فيجمع الورشة والتطبيق.
- نسختان: رمز وحده (للأيقونة)، ورمز + كلمة "ورشة" + Warsha (أفقي).
- يُرسم كـ SVG نقي بمسار واحد قابل للتلوين، فيعمل بلون واحد وعلى الخلفيات الفاتحة والداكنة.

### الألوان (متغيرات)
| الدور | القيمة |
|---|---|
| Ink (الخلفية الداكنة) | #0E1116 |
| Surface | #171C24 |
| Copper (الأساسي) | #E8742B |
| Teal (الثانوي/نجاح) | #2DBFA3 |
| Paper (الفاتح) | #F6F1E9 |
| Text muted | #9AA4B2 |
- الوضع الداكن هو الأساس، والفاتح اختياري. تباين النص يحقق WCAG AA.

### الخطوط (مجانية بترخيص OFL)
- العناوين والشعار: Reem Kufi (طابع حِرفي عربي).
- الواجهة والنص: IBM Plex Sans Arabic، وللأرقام واللاتيني: IBM Plex Sans.
- الأكواد والسجل المباشر: JetBrains Mono.

### الملفات المتأثرة عند التنفيذ
- جديد: `assets/logo-mark.svg`, `assets/logo-horizontal.svg`, `assets/icon-1024.svg`, `assets/BRAND.md` (الألوان والخطوط وقواعد الاستخدام)
- تعديل: `assets/banner.svg` (إعادة رسم كاملة)، `README.md` (الترويسة فقط)، `www/index.html` (شاشة بداية بالهوية الجديدة + متغيرات CSS)
- تعديل: أيقونات `android/app/src/main/res/mipmap-*` و`ic_launcher_foreground` (تُولَّد من الـ SVG)
- تعديل: `capacitor.config.json` (appName → "Warsha ورشة")

### خارج نطاق هذا المقترح
لا يشمل تغيير appId (قرار منفصل لأنه يؤثر على التثبيت والتحديث)، ولا قرار اسم المنتج النهائي إن كان هناك تردد بين Warsha وAppForge.

## 3) أسئلة للطرف الآخر
1. هل توافق على اتجاه "الحرف و + هاتف" أم تقترح بديلاً؟
2. هل النحاسي (Copper) + الأخضر المزرق مناسبان، أم تفضّل لوحة أخرى؟
3. هل تعترض على تغيير appName دون appId في هذه المرحلة؟

## 4) آلية التنفيذ بعد الموافقة
دفعة واحدة (commit واحد) تشمل الأصول ثم README ثم الواجهة ثم الأيقونات، ويُتحقق من نجاح بناء الـ APK على GitHub Actions قبل إعلان الإنجاز.
