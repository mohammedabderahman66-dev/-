# Warsha (ورشة)

**ورشة بناء تطبيقات أندرويد (وقريباً iOS) بدون الحاجة لخبرة برمجية.**

يصف المستخدم فكرة التطبيق الذي يريده، فتُبنى له نسخة تطبيق قابلة للتثبيت مباشرة — دون الحاجة لحاسوب، أو تثبيت أدوات تطوير، أو معرفة برمجية مسبقة.

## المشكلة التي يحلها

أي شخص يملك فكرة تطبيق بسيط لاستخدامه الشخصي (أداة، متتبع، حاسبة، مفكرة مخصصة...) يصطدم عادة بحاجز تقني: تثبيت بيئة أندرويد كاملة، تعلّم لغة برمجة، أو الاعتماد على مبرمج. هذا المشروع يزيل هذا الحاجز بالكامل.

## كيف يعمل

1. المستخدم يصف التطبيق المطلوب.
2. يُولَّد كود المشروع (Vite/React + Capacitor).
3. يُرفع المشروع تلقائياً إلى GitHub.
4. GitHub Actions يبني التطبيق فعلياً إلى ملف تثبيت جاهز (APK، ولاحقاً حزمة iOS).
5. يحصل المستخدم على رابط تحميل مباشر لتثبيت تطبيقه.

كل خطوات التوليد والبناء والتصحيح تتم بالتعاون بين GitHub وClaude — لا اعتماد على Google AI Studio أو أي منصة توليد خارجية أخرى.

## الحالة الحالية

- ✅ قالب Capacitor أساسي + خط أنابيب بناء APK عبر GitHub Actions (هذا المستودع).
- 🔜 تسجيل دخول سهل للمستخدمين (Device Flow).
- 🔜 اختيار مزوّد مفتاح API مع تدوير تلقائي بين عدة مفاتيح.
- 🔜 طرفية/سجل مباشر داخل التطبيق يعرض خطوات البناء لحظياً.
- 🔜 دعم بناء iOS من نفس الكود المصدري.
