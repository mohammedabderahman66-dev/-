## 💡 المشكلة التي يحلها

أي شخص يملك فكرة تطبيق بسيط لاستخدامه الشخصي (أداة، متتبع، حاسبة، مفكرة مخصصة...) يصطدم عادة بحاجز تقني: تثبيت بيئة أندرويد كاملة، تعلّم لغة برمجة، أو الاعتماد على مبرمج. **Warsha** يزيل هذا الحاجز بالكامل.

## ⚙️ كيف يعمل

```
   وصف الفكرة  →  توليد الكود  →  رفع إلى GitHub  →  بناء تلقائي  →  رابط تحميل
```

1. المستخدم يصف التطبيق المطلوب.
2. يُولَّد كود المشروع (Vite/React + Capacitor).
3. يُرفع المشروع تلقائياً إلى GitHub.
4. **GitHub Actions** يبني التطبيق فعلياً إلى ملف تثبيت جاهز (APK، ولاحقاً حزمة iOS).
5. يحصل المستخدم على رابط تحميل مباشر لتثبيت تطبيقه.

كل خطوات التوليد والبناء والتصحيح تتم بالتعاون بين **GitHub** و**Claude** — لا اعتماد على أي منصة توليد خارجية أخرى.

## 🗂️ هيكل المشروع

```
.
├── android/                 # مشروع أندرويد الأصلي (Capacitor)
├── assets/                  # الهوية البصرية (بانر، شعار)
├── www/                     # الواجهة (Vite/React)
├── .github/workflows/       # خطوط بناء APK التلقائية
├── capacitor.config.json
└── package.json
```
